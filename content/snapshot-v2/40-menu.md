# The menu

Press MENU on the home screen to open the menu. The menu is a list of rows. A row is a number, a choice, a switch, or a screen.

## Change a setting

1. Press UP or DOWN to move the cursor to the row.
2. Press MENU. A number row opens the number editor. A choice row opens the choice editor. A switch row changes at once.
3. Press UP or DOWN to change the value.
4. Press MENU to keep the value and go back to the list.

NOTE: The board does not keep a change while it is locked. See [Lockout](#lockout).
